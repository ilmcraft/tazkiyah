### Full description — English

```
Tazkiyah — a daily path to self-purification.

Curated Bangla Islamic lectures in one place, organised by speaker and topic, made for focused listening and watching — no suggestions, comments or rabbit holes.

Features
• Lectures by speaker and topic, with the number of lectures in each topic
• Length, publish date and series part for every lecture
• A focused player: only the lecture, nothing else
• Audio-only mode, listening with the screen off, lock-screen controls
• Save for offline listening
• Resume where you left off
• Favorites, history, sleep timer, playback speed
• Bangla search that understands spelling variants
• Several Bangla fonts, light and dark themes
• New lectures arrive automatically

Speakers: Dr. Shamsul Arefin Shakti, Asif Adnan, Mufti Harun Izhar, Jakaria Masud, Ahmad Rafique — more coming.

Privacy: no account, no ads, no personal data collected.

Note: the lectures belong to their speakers and uploaders. Videos play in YouTube's player. This app is not affiliated with any speaker, organisation or YouTube.

Website: https://mdhelaluddin-ctg-bd.github.io/tazkiyah/
Contact: https://github.com/ilmcraft/tazkiyah/issues
```

## Release

- Track: **Closed testing** (new personal accounts need 12 testers opted in for 14 days before production).
- Release name: `1.2.1 (4)`.
- Release notes (bn-BD): `প্রথম প্রকাশ: বক্তা ও বিষয়ভিত্তিক বাংলা ইসলামিক লেকচার।`
- App signing: Play asks once, at the first upload. **Use the existing release key** (Play Console → "Use a different key" → export with Google's PEPK tool) so the Play and GitHub builds share a signature and users can move between them; a Google-generated key cannot be changed later.
